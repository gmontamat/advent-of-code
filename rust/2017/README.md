# Advent of Code 2017

**Not following advent calendar**. My verdict: This year is pretty uniform in terms of difficulty. No problem really
stands out as extremely difficult which makes it a great set of problems for learning a new language. Speaking of
langugages, rust was fun to learn. The tooling that comes with it is great: `cargo` for managing compilation and
dependencies and the `rust-analizer` VSCode addon provides great insights as you code regarding ownership and data type
issues. Understanding ownership was tedius at first but as you encounter that "enforcing no undefined behaviour" limits
your segmentation faults at runtime, you begin to appreciate it. Finally, the data structures the language
provides are helpful and easy to work with (speaking of the `Vec` and `HashMap` in particular).
